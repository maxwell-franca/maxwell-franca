## 📌 Projetos em destaque

| Projeto | Descrição |
| --- | --- |
| **Pulso** | To-do list inteligente com tarefas cíclicas, streak e histórico de 30 dias. Tem API REST, endpoint MCP para agentes de IA e webhooks para n8n. |
| **Triagem de e-mails com IA** | Fluxo n8n + Ollama (Qwen 2.5 7B) em Docker que classifica e-mails por tópico e urgência, registra compromissos na agenda e envia um resumo diário. Tudo local. |
| **Agente Hermes** | Assistente de IA em Docker que organiza pastas de trabalho e entrega pesquisas técnicas com fontes citadas. |
| **MesaClima** (ESP32) | Acessório de mesa com hora e clima. Configuração de WiFi por portal cativo, localização por IP e reset de fábrica. |
| **Relógio Estação** (ESP32) | Relógio NTP com clima e cotação de dólar, euro e bitcoin em display OLED. |
| **Biblioteca offline** (ESP32) | Servidor web com portal cativo, login com bloqueio por tentativas erradas e download de arquivos, sem internet. |
| **Oráculo Generativo** (ESP32) | Servidor web local que gera frases por gramática de regras e roda o Jogo da Vida no display. |
